# How do I compare two groups?

You need a column that shows the group of each person. Examples are class year or first-generation status.

1. On **Load**, open **More options**. Choose the columns to keep under **Respondent details to keep**. If each person answered several questions in separate columns, choose the one-column-per-question layout there too.
2. Code the answers as usual.
3. On **Explore**, open **Analysis**. Then open **By group**. Choose the detail to compare.
4. Switch the display to **% within group (normalised)**. Groups are seldom the same size. Percents make them comparable.

**Good to know.** In a small group, a few answers can change a percent by a large amount. For this reason, QualSafe shows the counts next to the percent.
