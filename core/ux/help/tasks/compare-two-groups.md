# How do I compare two groups?

You need a column that says which group each person is in, such as class year or first-generation status.

1. On **Load**, open **More options** and choose the columns to keep under **Respondent details to keep**. If each person answered several questions in separate columns, choose the one-column-per-question layout there too.
2. Code the answers as usual.
3. On **Explore**, open **Analysis**, then **By group**. Choose the detail to compare.
4. Switch the display to **% within group (normalised)**. Groups are rarely the same size, and percents are what make them comparable.

**Good to know.** With a small group, a few answers can swing a percent a long way. The counts are shown beside it for that reason.
