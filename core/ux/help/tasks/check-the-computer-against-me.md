# How do I check the computer's coding against mine?

This check tells you how far you can trust the computer for your own themes.

1. On **Code**, choose **Code with a written codebook**. Run it. The first time, it needs a one-time download. QualSafe asks before it downloads anything.
2. Open **Code a sample yourself**. QualSafe picks a random sample of answers. Tick the codes that apply to each answer. QualSafe does not show the choices of the computer while you work.
3. Open **See how it compares with you**. For each code, you see how far you and the computer agree. You also see the share of answers that you both coded the same way. You see how many answers each figure uses.

**Good to know.**

- QualSafe shows agreement for each code separately. It never shows one overall score.
- A code that has very few answers has no agreement figure. Such a figure has no meaning.
- If a code has poor agreement, make its definition tighter. Then run it again.
