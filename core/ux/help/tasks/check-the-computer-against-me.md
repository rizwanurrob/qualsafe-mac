# How do I check the computer's coding against mine?

This tells you how far you can trust it for your own themes.

1. On **Code**, choose **Code with a written codebook** and run it. (It needs a one-time download the first time. QualSafe asks before it downloads anything.)
2. Open **Code a sample yourself**. QualSafe picks a random sample of answers. You tick the codes that apply to each; the computer's choices are not shown while you do.
3. Open **See how it compares with you**. For each code you see how far you and the computer agree, the share of answers you both coded the same way, and how many answers each figure rests on.

**Good to know.**

- Agreement is shown for each code separately, never as one overall score.
- A code applied to very few answers gets no agreement figure, because it would not mean anything.
- If a code agrees poorly, tighten its definition and run it again.
