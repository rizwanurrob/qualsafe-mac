# How do I code an interview?

1. Open **Interviews**. On **Add transcripts**, press **Add transcripts from a folder**. Confirm the privacy check.
2. On **Code**, choose a transcript. Drag across a passage. Press the number key of a code. A coloured bar shows in the margin. Press **Ctrl+Z** to undo.
3. On **Codebook**, give each code a short definition. Rename or merge codes that overlap.
4. On **Explore**, see which codes come up and in which people. Click a bar to read the passages.

**Good to know.** Add your codes before you start to code. You can add and change codes at any time.
