# How do I code an interview?

1. Open **Interviews**. On **Add transcripts**, press **Add transcripts from a folder** and confirm the privacy check.
2. On **Code**, choose a transcript, drag across a passage and press a code's number key. A coloured bar appears in the margin. **Ctrl+Z** undoes.
3. On **Codebook**, give each code a short definition. Rename or merge codes that overlap.
4. On **Explore**, see which codes come up, in whom, and click a bar to read the passages.

**Good to know.** Add your codes before you start coding, but you can add and change them as you go.
