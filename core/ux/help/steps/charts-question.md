# Charts, step 2: Pick a question

**What this step is for.** Choose the one question (a column) you want to chart. QualSafe picks a chart that fits the kind of answers: bars for choices, stacked bars for a scale, a histogram for numbers.

**What to do**

1. Choose the question.
2. To compare groups, also choose a column to **split by**, such as class year.

**Good to know**

- Each bar is labelled with the percent, how many chose it, and how many answered, for example 26% (63/240), so a small group is not mistaken for a big one.
- You can change the chart type later, in the next step.
