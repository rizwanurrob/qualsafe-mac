# Charts, step 2: Pick a question

**What this step is for.** Choose the one question (a column) that you want to chart. QualSafe picks a chart that fits the kind of answers. Choices use bars. A scale uses stacked bars. Numbers use a histogram.

**What to do**

1. Choose the question.
2. To compare groups, also choose a column to **split by**. An example is class year.

**Good to know**

- Each bar has a label. The label shows the percent, how many people chose it, and how many people answered. An example is 26% (63/240). This stops you from mistaking a small group for a big group.
- You can change the chart type in the next step.
