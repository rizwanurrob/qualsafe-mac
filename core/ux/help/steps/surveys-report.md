# Surveys, step 5: Make your report

**What this step is for.** Save the files that you need to share or keep.

**What to do**

1. Choose the report that you want. Reviewers and ethics boards ask for the **Methods and reliability appendix**. Other reports are the analysis report, the codebook report, a spreadsheet of the tables, and the audit trail.
2. Decide if quotes from the answers can appear. This option is off until you switch it on. QualSafe writes what you choose.
3. Press the main button. Choose where to save the file.

**Good to know**

- The methods appendix says how people and the computer coded the answers. It says how well the coders agreed on each theme. It also gives the limits of those numbers. It contains no response text.
- Respondent details in your file stay out of the reports. Include them only if you want them.

**Done.** You can go back and change any earlier step. A later step tells you if you must run it again.
