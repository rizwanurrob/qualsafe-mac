# Surveys, step 3: Code the answers

**What this step is for.** Coding means deciding which themes each answer is about. You choose how, then run it and review the result.

**The three ways**

- **Suggest codes for me to check.** QualSafe suggests a code for every answer. Fastest. You still check the answers it was unsure about.
- **Code with a written codebook.** You write a definition for each theme, with what to include and what to leave out. QualSafe reads each answer against those definitions. This is a preview. It needs a one-time download of a large file, and it is slow on a laptop (minutes for a few dozen answers). Check it against your own coding before you rely on it.
- **I'll code by hand.** You read each answer and tick the themes that apply. Best for a small set, or to see how well the computer's suggestions agree with you.

**Reviewing.** After a run, look at the answers marked **Needs your review**. Those are the ones QualSafe was unsure about. Your correction is the real analysis; the computer's pass is a first draft.

**Good to know**

- Agreement between you and the computer is reported for each theme separately (Cohen's kappa), never as one overall score. A theme used on very few answers gets no figure, because a figure from a handful of answers would mislead.
