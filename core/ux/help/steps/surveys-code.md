# Surveys, step 3: Code the answers

**What this step is for.** Coding means that you decide which themes each answer is about. You choose how to do it. Then you run it and review the result.

**The three ways**

- **Suggest codes for me to check.** QualSafe suggests a code for every answer. This way is the fastest. You must still check the answers that QualSafe was not sure about.
- **Code with a written codebook.** You write a definition for each theme. Say what to include and what to leave out. QualSafe reads each answer against your definitions. This way is a preview. It needs a one-time download of a large file. It is slow on a laptop. A few dozen answers take minutes. Compare it with your own coding before you trust it.
- **I'll code by hand.** You read each answer and tick the themes that apply. This way is best for a small set of answers. It also shows how well the suggestions of the computer agree with you.

**Reviewing.** After a run, look at the answers marked **Needs your review**. QualSafe was not sure about these answers. Your corrections are the real analysis. The computer makes a first draft.

**Good to know**

- QualSafe reports agreement between you and the computer for each theme separately (Cohen's kappa), and never as one overall score.
- A theme that has very few answers has no figure. A figure from a few answers is not reliable.
