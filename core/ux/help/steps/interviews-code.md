# Interviews, step 2: Read and code

**What this step is for.** Read each transcript and attach codes to the passages that matter.

**What to do**

1. Choose a transcript and read it.
2. Drag across a passage to select it, then press a code's number key, or use **Apply to selection**.
3. A coloured bar appears in the margin. Click it to return to the passage.
4. **Ctrl+Z** undoes, **Ctrl+Y** redoes.
5. **Remove selected coding** takes a code off a selected passage.
6. If you have an interview guide, open **More options**, press **Add an interview guide**, then **Suggest codes from the guide**. QualSafe matches each question you asked, and the answer that followed, to your guide's themes. These are suggestions to read and correct, and **Remove the guide's suggestions** takes them all away again without touching your own coding.

**Good to know**

- If you confirmed who is speaking, the interviewer's words are in italics. If you select only the interviewer's words to code, QualSafe asks first, because it is usually the participant's words you want.
- Each coding remembers exactly which words you selected, so every count can be traced back to them.
- The guide matching needs the analysis engine and a small model, and the first run can take a few minutes. It shows its counts when it finishes, including answers that fit no theme: read those too.
- Your work is saved as you go.
