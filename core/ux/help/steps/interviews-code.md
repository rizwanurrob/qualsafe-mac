# Interviews, step 2: Read and code

**What this step is for.** Read each transcript. Attach codes to the passages that matter.

**What to do**

1. Choose a transcript and read it.
2. Drag across a passage to select it. Then press the number key of a code, or press **Apply to selection**.
3. A coloured bar shows in the margin. Click the bar to go back to the passage.
4. Press **Ctrl+Z** to undo. Press **Ctrl+Y** to redo.
5. Press **Remove selected coding** to take a code off a selected passage.
6. If you have an interview guide, open **More options**. Press **Add an interview guide**. Then press **Suggest codes from the guide**. QualSafe matches each question that you asked, and the answer that followed, to the themes of your guide. Read and correct these suggestions. Press **Remove the guide's suggestions** to take them all away. This does not change your own coding.

**Good to know**

- If you confirmed who is speaking, the words of the interviewer are in italics. Usually you want the words of the participant. If you select only the words of the interviewer, QualSafe asks you first.
- Each coding remembers the exact words that you selected. So you can trace every count back to those words.
- The guide matching needs the analysis engine and a small model. The first run can take a few minutes. When it ends, it shows its counts. These include the answers that fit no theme. Read those answers too.
- QualSafe saves your work as you go.
