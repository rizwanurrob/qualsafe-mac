# Charts, step 1: Open a spreadsheet

**What this step is for.** Make a chart from a table of numbers or choices, such as a survey with tick-box and scale questions.

**What to do**

1. Press **Open a CSV or Excel file**, or **Use the sample spreadsheet** to see how it works.
2. If a workbook has several sheets, choose the one you want.

**Good to know**

- The file is read, never changed.
- If apostrophes or accents look wrong, save the file from Excel as plain CSV and open it again.

**Next:** Pick a question.
