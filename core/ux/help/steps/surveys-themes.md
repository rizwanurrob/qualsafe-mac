# Surveys, step 2: Choose your themes

**What this step is for.** A theme (a code) is a short label for something people say, such as "Money worries". You list the themes; QualSafe, or you, then decide which answers each one fits.

**What to do**

1. Start from a ready-made list, or type your own, one theme per line.
2. Give each theme a name a stranger would understand. A few clear themes work better than many overlapping ones.
3. If you plan to code with a written codebook, add a definition for each theme (what counts, and what does not). That is in **More options**.

**Good to know**

- You can change the list later. Answers you have already coded keep their codes.
- The names you choose appear in every chart and report, so choose wording you are happy to show.
