# Surveys, step 2: Choose your themes

**What this step is for.** A theme (a code) is a short label for something that people say. An example is "Money worries". You make a list of themes. Then QualSafe or you decide which answers fit each theme.

**What to do**

1. Start from a ready-made list, or type your own list. Put one theme on each line.
2. Give each theme a name that a stranger can understand. A few clear themes are better than many themes that overlap.
3. If you plan to code with a written codebook, add a definition for each theme. Write what counts and what does not count. Find this under **More options**.

**Good to know**

- You can change the list later. Answers that you already coded keep their codes.
- The names that you choose show in every chart and report. Choose words that you are happy to show.
