# Interviews, step 4: Explore across interviews

**What this step is for.** See patterns across people. See which codes come up, in which people, and in which words.

**What to do**

- Open **Analysis** to count codes by interview or by group. Click a bar to read the passages.
- Use **Search** to find passages by word or by code.
- Open **Charts of themes** to turn a result into a picture.
- Use **Model an outcome** and **Query** for more questions. **Query** is under **More options**.

**Good to know**

- If you have few interviews, the counts are small. Read the passages. Do not read only the numbers.

**Next:** Report.
